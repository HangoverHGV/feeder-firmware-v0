# Feeder firmware

Feeder firmware for fully custom 3D printable Feeder, i will use it for cats, but i am trying to make it work for dogs also, this is just an idea.

# The Idea

The feeder body will be fully 3D printable wit models uploaded here in STEP format. Everything will be open source. KICAD model a smaller footprint. 
The Feeder should be easy to integrate in Home Assistant, mode on this later.

## Components:
  1. ESP32-something (maybe with camera)
  2. Camera
  3. Pressure Sensor
  4. TOF sensor or another pressure sensor for verifying the quantity of food.
  5. 3D printable Models

## Language

For this project i will use Rust, because I like Rust more than C/C++ :)
